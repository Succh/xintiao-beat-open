# 心跳 Beat（暂定名）设计规范 v0.1

风格：柔和粉紫、偏甜的情侣风。干净、留白多，一屏只做一件事。
源文件：`src/`（HTML/CSS，可直接参考给 Vela `.ux` 和 Android 用）。重新出图：`src/render.sh`。

## 2. 字体
- 出图：Noto Sans CJK SC + Noto Color Emoji。
- 真机：手环用系统字体（Vela 默认 MiSans），手机用系统字体（HyperOS 为 MiSans）。不额外打包字体。
- 字号（手环 336×480）：标题 24 / 大按钮 30 / 名字 24 / 正文 19–21 / 说明 15–17，最小不低于 14。
- 字号（手机，按 540 宽设计，@2x 出图）：页面标题 26 / 卡片标题 16–19 / 正文 15 / 说明 12–13。
- 粗细只用两档：Regular(400/500) 和 Bold(700)。

## 4. 组件
- **TA 的状态卡**：头像（大 emoji 放在圆形底上）+ 名字 + 在线圆点 + 状态短句（胶囊）+ 更新时间。
- **想你了大按钮**：粉色胶囊，手环高 104、手机高 72；单击短振，长按长振。整个界面里最显眼，只此一个。
- **心情磁贴**：2 列网格，emoji 34 + 文字，选中时紫色 3px 描边 + 抬起底色。
- **短语列表项**：高 64，左 emoji、中文字、右侧圆形发送箭头；刚发出的一条整行变粉色。
- **收到想念**：紫色头像圈 + 两圈同心光环 + 四周散落的爱心（实现时用缩放/透明度动画，循环约 1.2s），配合 `vibrate('long')`。
- **配对码**：6 位数字分两组（3+3），每位一个深色格子；有效期 5 分钟。
- **手机双人状态卡**：左 TA（粉→紫浅渐变），右 我（白），下方标注各自设备与模式。
- **时间线条目**：圆形图标（TA = 粉雾底，我 = 紫雾底）+ 一句话 + 小字补充 + 右侧时间。
- **设备模式单选卡**：选中时粉色 2px 描边 + 实心圆点。

## 5. 平台说明
- **手环 9 Pro（336×480）**：纯黑底，只用纯色块（Vela 建议不用渐变），点击区域高度 ≥ 58（主按钮 104）。每屏只做一件事。
- **Redmi Watch 5 / 6（432×514，圆角更大约 90）**：已核实 Watch 6 为 2.07" 432×514（mi.com 官方规格）。沿用同一套组件，按宽度等比放大约 1.07–1.28 倍，四角多留边距。
- **Redmi Watch 3（390×450）**：装不了第三方应用，只能显示系统通知。样式由手表决定，我们只能控制标题和正文，建议格式：标题 `💗 老板`，正文 `想你了 🥰` + 第二行 `心情：😪 累了`。
- **手机（1080×2400）**：浅粉底 + 白卡片，可以用柔和渐变；底部三栏导航：首页 / 记录 / 设置。
